- **2026-11-11 · v0.2.8** — v0.2.7 installed on chiefmonkey.art. The owner measured `events.db` at 1,003 MB with no free pages, and almost all events newer than 90 days. The bulk came from 1,397 old kind-3 follow lists (plus 143 kind 0 and 92 kind 10002) that should have been replaced; their 1,027,567 tag rows were 63% of `event_tags`. Root cause: applesauce's `EventStore` removes replaced versions with `database.remove(event)`, which the native SQLite database fails silently. The installer compacts the store once before the flip (disk check, checked backup, VACUUM, safe to re-run, counts in the deploy log) and keeps two releases instead of five. Rehearsal on the dev copy: 370.6 MB to 190.2 MB, 459 old versions removed, about 6 s. Tests: 33 repo checks, 43 service tests (new: replacement, tie both ways, out-of-order, addressable `d`, stray `d` on kind 3, other kinds untouched, the upstream bug itself, compaction counts, backup, re-run, low-disk skip, backup rotation).
